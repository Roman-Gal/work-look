Ingress and supervision:
 - WorkLook can forward POST /telegram/webhook and /translator/telegram/webhook to
   fixed localhost services. Secret validation, body limits and redirects disabled.
 - Both routes currently return 503: integration ports/secrets are intentionally
   disabled. The website cannot redirect updates from the working local bots.
 - Cron calls current/tools/mydevil/worklook-worker.sh every minute; lockf prevents
   overlap and each worker is bounded to 300 seconds/128 MB between messages.
   It only processes button-created runs; it does not schedule autonomous searches.
 - tools/mydevil/bot-service.sh planner|translator uses FreeBSD daemon -r only after
   validating the local config. With placeholders it reports standby and exits
   before network access. A copy is installed as apps/bot-service.sh.
 - Bot autostart cron entries are intentionally absent until activation is approved.
 - Restart a WorkLook worker: php84 bin/console messenger:stop-workers --env=prod;
   cron will start the next worker. Run commands from apps/work-look/current.
 - Deployment logs and a backup of the original cron live in apps/deploy-logs/.
