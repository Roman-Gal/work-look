PHP release note:
 devil www restart does not restart PHP domains. Changing symlink releases can require
 targeted old/new index.php OPcache invalidation in the web SAPI, then immediate removal
 of the protected one-use helper. CLI OPcache is separate. Always verify the new route.
 Public code dirs/assets need 0755/0644, private state 0700 and secrets 0600; a restrictive
 extraction umask affects FreeBSD symlink modes and AssetMapper output too.
